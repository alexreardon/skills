# skills

Alex Reardon's collection of [agent skills](https://vercel.com/docs/agent-resources/skills).

## Install

```bash
npx skills add alexreardon/skills
```

To install a single skill from this repo:

```bash
npx skills add alexreardon/skills --skill cook-me
```

## Skills

- [`cook-me`](skills/cook-me/SKILL.md) — opinionated design-interview skill that walks you down every branch of a plan or design, one tight question at a time, with lettered options ordered by preference.
